**חשוב:** n8n רץ רק כשהמחשב דולק והחלון שלו פתוח. מה שהתפספס ירוץ בפעם הבאה.

## כללי הבטיחות של אוטומציית המייל

- "ההרצאה הקרובה" בלי תאריך = המופע הבא אחרי שעת שליחת המייל. תאריך מפורש תמיד גובר.
- הודעה לקבוצת תרגול אחרת – לא נוגעים, רק מדווחים.
- ספק (קורס לא ברור, קבוצה לא ידועה בתרגול, תאריך שלא נופל על שיעור אמיתי) – השינוי מחכה לאישור שלך.
- תוכן המייל הוא מידע בלבד. האוטומציה לא שולחת מיילים, לא עונה, ולא נוגעת ביומן גוגל.

## התקנה – פעם אחת (כ-20 דקות)

### 1. Supabase
1. להירשם ב-[supabase.com](https://supabase.com) וליצור פרויקט (חינם).
2. SQL Editor ← להדביק את כל `supabase/schema.sql` ← Run.
3. Authentication ← URL Configuration ← Redirect URLs: להוסיף `http://localhost:5180` (ובהמשך גם את כתובת האתר בגיטהאב).
4. Project Settings ← API: להעתיק את ה-URL, את ה-`anon` key ואת ה-`service_role` key.

### 2. לחבר את האפליקציה
1. להעתיק `js/config.example.js` ל-`js/config.js` ולמלא URL ו-anon key.
2. להפעיל: `node tools/serve.js` ולפתוח http://localhost:5180
3. גיבוי והגדרות ← ענן ואוטומציות ← להזין מייל ← ללחוץ על הקישור שהגיע במייל.
4. ללחוץ **"העלאת קובץ הנתונים לענן"**, ולהעתיק את **מזהה המשתמש**.

### 3. הסודות של n8n
להעתיק `automations/.env.example` ל-`automations/.env` ולמלא (ההסברים בתוך הקובץ).

### 4. להפעיל את n8n
```powershell
powershell -ExecutionPolicy Bypass -File automations\start-n8n.ps1
```
**התקנה חד-פעמית של n8n** (לפני ההפעלה הראשונה):

```bash
npm install -g n8n --ignore-scripts
```
```bash
cd "$env:APPDATA

```

ה-`--ignore-scripts` מדלג על בניית חבילת Kafka, שדורשת Visual Studio ושה-workflows האלה לא נוגעים בה. הפקודה השנייה מורידה את הבינארי של sqlite3, שבלעדיו n8n לא פותח את מסד הנתונים שלו. אחר כך לפתוח http://localhost:5678 וליצור משתמש מקומי.

### 5. לייבא את ה-workflows
ב-n8n: Workflows ← ⋮ ← Import from File ← לבחור כל אחד מהקבצים ב-`automations/workflows/`.

### 6. מייל (רק ל-workflow מספר 2) — דורש אימות דו-שלבי בגוגל

**מצב: כבוי.** החיבור ל-Gmail דרך IMAP מחייב *סיסמת אפליקציה*, וגוגל מציעה אותה רק בחשבון שבו **אימות דו-שלבי מופעל**. בלעדיו העמוד `myaccount.google.com/apppasswords` עונה "ההגדרה שאת מחפשת אינה זמינה בחשבון שלך", גם כשיש מפתחות גישה והתראות לטלפון.

להפעלה בעתיד, לפי הסדר:
1. חשבון Google ← אבטחה ← **אימות דו-שלבי** ← להפעיל.
2. `myaccount.google.com/apppasswords` ← ליצור סיסמה בשם `n8n` ← 16 אותיות.
3. ב-n8n, בצומת "מייל חדש" ← Credential ← IMAP: המשתמש והשרת כבר מוגדרים (`imap.gmail.com`, פורט 993, SSL), להדביק את הסיסמה ולשמור.
4. מפתח Claude: `node tools/set-secret.js ANTHROPIC_API_KEY` ולהדביק בדף שנפתח. בלי תקציב בקונסול הקריאות יידחו.
5. להפעיל את ה-workflow.

חלופה בלי לשנות הגדרות בחשבון: צומת Gmail עם OAuth2, שדורש פרויקט ב-Google Cloud והגדרת הרשאות.

### 7. לבדוק ולהפעיל
בכל workflow: ללחוץ **Test workflow** (ב-1, 3, 4 יש node "בדיקה ידנית"). אם יצא ירוק – להדליק את המתג **Active**. באפליקציה: רענון ← "📬 עדכונים".

## לשנות את הלוגיקה

הקוד שב-workflows נוצר אוטומטית. משנים ב-`automations/lib/` (או ב-`js/logic.js`), ואז:

```bash
node tests/automations.test.js
```
```bash
node automations/build.js
```
ומייבאים מחדש את הקובץ שהשתנה.
