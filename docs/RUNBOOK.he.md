# מדריך תפעול – האוטומציות

מה עושים כשהאוטומציות לא רצות. האוטומציות רצות ב-GitHub Actions (ADR 0001).

## איך אני יודעת שיש בעיה

1. **באפליקציה:** בכרטיס "עדכונים מהאוטומציות" מופיעה שורת אזהרה כשאוטומציה לא רצה בזמן או נכשלה. כשהכול תקין לא מופיע כלום.
2. **בתיבת ההודעות:** התראה "האוטומציה נכשלה", אחת ביום לכל אוטומציה.
3. **במייל מ-GitHub:** ריצה שנכשלה שולחת התראה. כדאי לוודא ב-GitHub ← Settings ← Notifications שהתראות Actions פתוחות.

כמה זמן נחשב "לא בזמן": סנכרון מודל 12 שעות (יש פער לילי רגיל של 9), תדריך בוקר ותזכורות 30 שעות.

## הגדרה חד-פעמית

להריץ ב-Supabase ← SQL Editor את הקובץ `supabase/schema.sql` מחדש. הוא בטוח להרצה חוזרת, ומוסיף את הטבלה `sync_state`. עד שזה נעשה האפליקציה פשוט לא מציגה חיווי.

## תרחישים

| מה רואים | סיבה סבירה | מה עושים |
| --- | --- | --- |
| "חסרות הגדרות: …" | סוד חסר ב-GitHub | Settings ← Secrets and variables ← Actions. להוסיף את השם שמופיע |
| "הערך נראה שגוי" | סוד שהודבק לא נכון | להדביק מחדש. רווחים ומירכאות מנוקים אוטומטית, כתובת חייבת להתחיל ב-https:// |
| סנכרון מודל נכשל ב-HTTP 4xx | קישור היומן של מודל פג או הוחלף | במודל: יומן ← ייצוא ← להעתיק קישור חדש ולעדכן את `MOODLE_ICS_URL` |
| כשל ב-HTTP 401 מול Supabase | מפתח השירות הוחלף | לעדכן את `SUPABASE_SERVICE_KEY` |
| אין ריצות בכלל | GitHub משבית workflow מתוזמן אחרי 60 ימים בלי פעילות בריפו | Actions ← automations ← Enable workflow, ולהריץ ידנית |
| ריצה מתעכבת בשעה או שעתיים | עומס אצל GitHub | לא צריך לעשות כלום. הודעות לא נכפלות |

## הרצה ידנית

ב-GitHub: Actions ← automations ← Run workflow, ובוחרים מה להריץ.

מהמחשב, אחרי מילוי `automations/.env`:

```powershell
node automations/run-local.js 1-moodle-sync
```

לכתוב עמוד קצר בלי האשמה: מה קרה, למה, ומה משתנה. אם זה חוזר, להוסיף שורה לטבלה למעלה.
