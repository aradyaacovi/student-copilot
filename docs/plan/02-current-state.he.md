## מגבלות שמקבלים

- משתמשת אחת בפועל, ולכן אין צורך בתשתית רב-משתמשים עכשיו.
- הלוגיקה והמסך מאוחדים בקבצים גדולים. זה בסדר בהיקף הזה, ויישקל מחדש רק אם הממשק יגדל.
- Actions יכול לאחר ריצה בכמה דקות. ההגנה: כל הודעה נשמרת עם מפתח ייחודי, וריצה כפולה לא משכפלת.

## מה לבדוק ביד לפני שמתחילים

1. האם הוגדרו GitHub Secrets ורצה ריצה מוצלחת אחת לפחות ב-Actions.
2. האם כללי ענף ו-secret scanning פעילים בהגדרות הריפו.
3. האם יש ענפים ישנים שאפשר למחוק (`chore/bump-actions-batch`, `feat/automations-on-actions` ועוד).
