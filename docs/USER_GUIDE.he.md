# 🎓 Student Copilot

עוזר אישי לסמסטר: כל הדרישות, הממוצע, תעדוף המשימות, הלו״ז, מעקב הקצב והסיכומים המצטברים – בדף אחד.
בלי התקנות, בלי שרת ובלי חשבון. נפתח בדפדפן, עובד גם בלי אינטרנט, ואפשר להעלות אותו ל-GitHub Pages.

## מה יש בו

4 לשוניות, ומסך אחד שעונה על השאלה "מה לעשות עכשיו":

| לשונית | מה היא עושה |
| --- | --- |
| **היום** | כרטיס "עכשיו" עם משימה אחת, התוכנית להיום לפי השעות הפנויות, ועדכונים מהאוטומציות. כל השאר מקופל |
| **לו״ז** | מערכת שבועית עם ביטולים, השלמות ודדליינים, מפת עומס של הסמסטר, וייצוא ליומן (`.ics`) |
| **קורסים** | כרטיס לכל קורס: איפה את בקצב, מה ההגשה הבאה, סימון "ראיתי". לחיצה על קורס פותחת דף עם הדרישות, ההגשות, הציון והסיכום המצטבר |
| **ממוצע** | ציון לכל קורס לפי המשקלות, כלל ה-56, ממוצע סמסטר ומצטבר, וכמה צריך במבחן כדי להגיע ליעד |
| ⚙️ | גיבוי, חיבור לענן, מצב כהה |

### איך נקבע סדר המשימות

לוגיקה אחת לכל סוגי המשימות (`buildPlan` ב-`js/logic.js`):

1. **הערכת שעות** לכל משימה לפי הסוג והמשקל בציון (הגשה של 20% ≈ 10 שעות, הרצאה להשלמה 1.5 שעות, מבחן של 90% ≈ 36 שעות). אפשר להזין שעות ידנית.
2. **מתי חייבים להתחיל** = מועד ההגשה פחות הימים שהעבודה דורשת.
3. **הסדר**: ככל שקרובים יותר למועד ההתחלה, המשימה גבוהה יותר. בשוויון, מה ששוקל יותר בציון קודם.
4. **התוכנית להיום** מתמלאת עד מספר השעות הפנויות (אחרי שיעורים בקמפוס, עד 19:30), עד שעתיים למשימה ביום. רק דדליין אמיתי של היום/מחר יכול לחרוג מזה.
5. **פיגור בהרצאות** מתפזר: 2 ביום, מהישן לחדש, הרצאה לפני תרגול. הרצאה מהשבוע האחרון נכנסת לפני התרגול הבא.
6. **חזרות מרווחות**: יום, שבוע וחודש אחרי שראית הרצאה (אפשר לכבות).

## אוטומציות

ארבע אוטומציות ב-n8n (סנכרון מודל, ביטולים מהמייל, תדריך בוקר, תזכורות) שכותבות ל-Supabase ומופיעות באפליקציה. הכול ב-[automations/README.md](automations/README.md).

## הפעלה

1. להוריד או לשכפל את הפרויקט.
2. ליצור את קובץ הנתונים האישי:
   ```bash
   cp data/sample-semester.js data/my-semester.js
   ```
   ובקובץ החדש לשנות את `window.SAMPLE_DATA` ל-`window.SEMESTER_DATA` ולמלא את הקורסים שלך.
3. לפתוח את `index.html` בדפדפן (לחיצה כפולה), או להריץ `node tools/serve.js` ולפתוח http://localhost:5180

בלי `my-semester.js` האפליקציה עולה במצב הדגמה.

## פרטיות – מה עולה לגיטהאב ומה לא

- `data/my-semester.js` נמצא ב-`.gitignore` ו**לא עולה**: שמות, מתרגלים, קבוצות, חדרים.
- הסימונים, הציונים והסיכומים שאת מוסיפה באפליקציה נשמרים **רק בדפדפן** (localStorage). כדאי לגבות מדי פעם בלשונית "גיבוי והגדרות".
- באתר ב-GitHub Pages יופיעו רק נתוני ההדגמה. כדי לראות שם את שלך: "גיבוי והגדרות" ← "טעינת my-semester.js" (נשמר רק בדפדפן שבו טענת).

## העלאה לגיטהאב

## עדכון הנתונים

כל המידע על הסמסטר נמצא בקובץ אחד: `data/my-semester.js`.

| רוצה לעדכן | איפה בקובץ |
| --- | --- |
| הרצאה בוטלה | `courses[].sessions[].cancelled` – להוסיף את התאריך |
| שיעור השלמה | `courses[].sessions[].extra` – `{ "date", "start", "end", "note" }` |
| הגשה / מבחן חדשים | `deadlines` |
| סיכום של הרצאה | `courses[].summaries` (או מהאפליקציה) |
| יום בלי לימודים | `semester.noStudyDates` |

אפשר גם לבקש מ-Claude לעשות את זה: בתיקייה `prompts/` יש הוראות מוכנות (עדכון קצב שבועי, צ׳קליסט יומי, תדריך שבועי), ו-`CLAUDE.md` מסביר לו את הפרויקט.
